# Cybersecurity-Policy-Simplifier-GenAI

Cybersecurity Policy Simplifier is a generative AI tool designed to bridge the gap between technical security requirements and everyday employee comprehension. Built on AWS PartyRock (powered by Amazon Bedrock), this application takes dense policy text (like NIST controls or internal Acceptable Use Policies) and translates it into accessible, plain-language formats.

Unlike standard AI wrappers, this app prioritizes AI safety and compliance. It utilizes strict prompt engineering to flag ambiguous policies rather than hallucinating rules, and it features an automated "Fidelity Audit" that compares the AI's simplified output against the original text to ensure no legal requirements were dropped or weakened.
